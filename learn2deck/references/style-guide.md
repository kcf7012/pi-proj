# Claude Orange 主題設計指南

> **權威來源**：`_pptx_helpers.py` + `learn2deck/lib/themes/claude-orange.yaml`
> **用途**：當需要客製化版面、新增版型、或調整視覺風格時參考

## 1. 設計哲學

Claude Code Plugin 系列簡報採用 **Claude 品牌橘 + 自學友善的米白** 風格：

- **簡潔**：避免多餘裝飾，內容為主
- **可讀**：高對比文字、合適行距
- **一致**：每張投影片都套用統一的標題列 + 底部品牌列
- **可掃描**：bullet + 表格 + 卡片三種主要資訊密度

## 2. 顏色系統

### 2.1 核心色票

| 名稱 | Hex | RGB | 用途 |
|:-----|:----|:----|:-----|
| `primary` | `#C75A1A` | (199, 90, 26) | Claude 橘，裝飾條、品牌列、強調 |
| `bg_cream` | `#FAF8F3` | (250, 248, 243) | 投影片背景米白 |
| `bg_gray` | `#F3F0E9` | (243, 240, 233) | 卡片背景淺米 |
| `dark` | `#2C2C2C` | (44, 44, 44) | 主要文字 |
| `gray_text` | `#6B6B6B` | (107, 107, 107) | 次要文字、副標、頁碼 |
| `white` | `#FFFFFF` | (255, 255, 255) | 卡片反白文字 |

### 2.2 輔助色（特殊用途）

| 名稱 | Hex | RGB | 用途 |
|:-----|:----|:----|:-----|
| `blue` | `#3B82F6` | (59, 130, 246) | 連結、強調標記 |
| `green` | `#16A34A` | (22, 163, 74) | 成功、完成狀態 |
| `red` | `#DC2626` | (220, 38, 38) | 警告、錯誤 |
| `code_bg` | `#1E1E1E` | (30, 30, 30) | 程式碼區塊背景（深色） |
| `code_fg` | `#E6E6E6` | (230, 230, 230) | 程式碼前景文字（淺色） |

### 2.3 主題 YAML 範例

完整主題定義見 `learn2deck/lib/themes/claude-orange.yaml`：

```yaml
name: claude-orange
description: Claude 品牌橘 + 米白背景
version: 1.0

colors:
  primary: "#C75A1A"
  bg_cream: "#FAF8F3"
  bg_gray: "#F3F0E9"
  dark: "#2C2C2C"
  gray_text: "#6B6B6B"
  white: "#FFFFFF"
  blue: "#3B82F6"
  green: "#16A34A"
  red: "#DC2626"
  code_bg: "#1E1E1E"
  code_fg: "#E6E6E6"

fonts:
  title: "Calibri"
  body: "Calibri"
  code: "Consolas"

font_sizes:
  cover_title: 44
  cover_subtitle: 20
  section_title: 40
  slide_title: 32
  slide_subtitle: 16
  body: 14
  body_small: 12
  caption: 10
  code: 12
  brand: 9
```

## 3. 字體系統

| 角色 | 字體 | 預設大小 | 用途 |
|:-----|:-----|:--------:|:-----|
| 標題 | Calibri | 32 pt | 每張投影片主標題 |
| 副標題 | Calibri | 16 pt | 主標下方的灰色說明 |
| 內文 | Calibri | 14 pt | bullet 文字 |
| 小字 | Calibri | 12 pt | 表格內容、次要資訊 |
| 程式碼 | Consolas | 12 pt（動態降級 11/10/9/8） | code 框內容 |
| 頁碼 | Calibri | 10 pt | 右上角「N / total」 |
| 品牌列 | Calibri | 9 pt | 底部品牌標 |

> **降級規則**：code 框行數 × 行高 > 5.5" 時自動降級字級（12 → 11 → 10 → 9 → 8 pt）

## 4. 版面系統

### 4.1 投影片尺寸

- **比例**：16:9
- **寬度**：13.333 inch
- **高度**：7.5 inch

### 4.2 安全區（Safe Zone）

所有內容必須在以下範圍內：

```
┌────────────────────────────────────────────────────┐
│ 橘色頂部條 (0 - 0.15")                              │
├────────────────────────────────────────────────────┤
│ 標題區 (0.3" - 1.15")                                │
├────────────────────────────────────────────────────┤
│                                                    │
│ 內容區 (1.3" - 7.0") ← 主要版面                    │
│                                                    │
├────────────────────────────────────────────────────┤
│ 品牌列 (7.1")                                       │
└────────────────────────────────────────────────────┘
```

| 區域 | Top | Bottom | 用途 |
|:-----|:----|:-------|:-----|
| 頂部裝飾條 | 0.0" | 0.15" | 橘色 accent line |
| 標題列 | 0.3" | 1.15" | 主標 + 副標 |
| **內容區** | **1.3"** | **7.0"** | **主要內容（高度 5.7"）** |
| 容忍下緣 | 7.0" | 7.35" | 超出會出 R3 warning |
| 品牌列 | 7.1" | 7.4" | 底部品牌標 + 來源 |

### 4.3 水平邊界

- **左邊界**：0.5"
- **右邊界**：12.833"
- **可用寬度**：12.333"

### 4.4 標準版面格線

```
左對齊版型（title_content / title_table / title_code）：
┌─────────────────────────────────────┐
│ [0.5"]                          [12.833"]
│ 標題區（0.3 - 1.15）                │
├─────────────────────────────────────┤
│ 內容區（1.3 - 7.0）                 │
│ 寬度：12.333"                       │
└─────────────────────────────────────┘

雙欄版型（two_column）：
┌──────────────────┬──────────────────┐
│ 左欄             │ 右欄              │
│ 0.5" - 6.4"      │ 6.9" - 12.833"   │
│ 寬度：5.9"       │ 寬度：5.933"     │
└──────────────────┴──────────────────┘

網格卡片（grid_cards）：
預設 3 欄，自動計算間距
```

## 5. 裝飾元素

### 5.1 頂部橘色條

- 位置：x=0, y=0
- 尺寸：寬 13.333" × 高 0.15"
- 顏色：`primary` (#C75A1A)
- 無邊框

### 5.2 標題列

- 主標題：x=0.5", y=0.3", 寬 11", 高 0.7"
  - 字體：Calibri 32pt bold
  - 顏色：`dark`
- 副標題（選用）：主標下方，16pt 灰色

### 5.3 頁碼

- 位置：右上角
- 格式：`{slide_num} / {total}`
- 字體：Calibri 10pt
- 顏色：`gray_text`

### 5.4 底部品牌列

- 左：x=0.5", y=7.1", "Claude Code Plugin 完整學習系列"
- 右：x=8", y=7.1", "📖 來源：{source}"
- 字體：Calibri 9pt
- 顏色：左 `primary`、右 `gray_text`

## 6. 設計原則 Checklist

當新增版型或調整版面時，確認：

- [ ] 內容在 1.3" - 7.0" 範圍內（不超過 7.35"）
- [ ] 水平在 0.5" - 12.833" 範圍內
- [ ] 標題用 Calibri 32pt bold
- [ ] 程式碼用 Consolas 12pt（含降級）
- [ ] 顏色只用主題定義的 11 個顏色
- [ ] 每張 slide 都有頂部橘色條
- [ ] 每張 slide 都有底部品牌列（cover 除外）
- [ ] 字級不小於 9pt（避免過小難讀）

## 7. 反模式（不要做）

- ❌ 用 `add_connector()` 畫箭頭（會造成空白）→ 用 `MSO_SHAPE.RIGHT_ARROW`
- ❌ 在 builder 內硬編碼顏色 → 從 `theme.get_color()` 取
- ❌ 用全域顏色常數（`COLOR_PRIMARY` 等）→ 已被移除
- ❌ 保留 `add_shape()` 回傳的參考長期使用 → 會 stale，每次從 `slide.shapes` 重拿
- ❌ 文字框不設 word_wrap → 長文字會跑出框外
- ❌ 用 emoji 當主要標記 → emoji 適合補充，不適合關鍵資訊
- ❌ 表格 cell 內放長段落 → 拆成多行或縮短
- ❌ cover / section_divider 加底部品牌列 → 會干擾大標視覺
